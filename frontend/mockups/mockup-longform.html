About
"I build production-grade AI that's thoughtful about both capability and responsibility."

I'm a data scientist and AI engineer focused on building tools that make a meaningful difference. Currently leading GenAI efforts at Southern New Hampshire University, where I design and deploy intelligent systems that serve thousands of students.

My work sits at the intersection of machine learning, software engineering, and education. I believe the most impactful AI isn't the most complex — it's the most considered. Every system I build starts with a real problem and ends with a real solution.

When I'm not shipping production ML systems, I'm working on QuiverDB — an embeddable graph database written in Rust — or exploring the frontiers of AI-assisted development with Claude Code.

AILA

AI Learning Assistant designed to tutor students while maintaining academic integrity. Built for scale at SNHU with LangGraph-based agent architectures that create conversational flows guiding students through problems rather than solving them directly.

AI/ML Education LangGraph Azure
  • Serves thousands of students across SNHU

  • Built on Azure with Databricks integration

02

QuiverDB

A graph database positioned as "DuckDB for graph retrieval" — fast, embeddable, and designed for AI workloads. The goal is to make graph-based retrieval as easy as spinning up a SQLite database, with production-grade performance.

Rust Graph Database AI Infra
  • Embeddable with zero configuration
  • Optimized for AI retrieval patterns
  • Written in Rust for performance
  • Simple API inspired by DuckDB
